# Кулінарний журнал

Українська інтерактивна кулінарна книга: блонді, фондан, пінчер.

- Статичний HTML/CSS/JavaScript без залежностей.
- Дані рецептів у `recipes.js`, спільний рушій у `app.js`.
- Налаштування, відмітки й нотатки зберігаються локально в браузері; синхронізації між пристроями немає.
- Таймери відраховують час за кінцевим timestamp; фонові сповіщення не гарантовані.
- Офлайн після першого завантаження з HTTPS.

## Додавання рецепта

Додай запис до `window.RECIPES` у `recipes.js`: унікальний id, назва, базові порції, форма, джерело, групи продуктів (ключ, назва, грами), план, кроки та таймери. Ключі в фігурних дужках у кроках підставляють масштабовані грами. Для нового типу випічки перевір логіку температури та партій у `app.js`.

## Публікація

Settings → Pages → GitHub Actions. Workflow `pages.yml` публікує статичні файли з main.

Адаптації не перевірені практичним випіканням. Орієнтуйся на готовність і термостійкість форми, а не тільки таймер.

## Обкладинки рецептів

Стандартні авторські SVG-ілюстрації знаходяться в `assets/covers/`. Поле `cover` у рецепті вказує на файл обкладинки. Вкладка «Фото» дозволяє завантажити та стиснути власне фото в браузері, відновити стандартну обкладинку або завантажити свою копію. Локальні фото не синхронізуються між пристроями та не комітяться автоматично. Щоб опублікувати власне фото як спільну обкладинку, додай файл до `assets/covers/`, онови `cover` і версію/список кешу у `sw.js`. Не зберігай приватні фото в публічному репозиторії без явного рішення.
